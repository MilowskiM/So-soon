# Until We’re Together Again

Static photo countdown website, ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root. `index.html` should be at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the **/(root)** folder, then save.

GitHub will show the public website address after the deployment finishes.

## Countdown setting

The countdown currently targets **October 30, 2026 at 7:30 PM Eastern Time**. To change it, edit the `TARGET_DATE` value at the top of `app.js`.

## Privacy

GitHub Pages sites are normally public. Anyone with the URL may be able to view the included photos.
